# scoregirls-news

「スコアガールズ」の **時事クイズ** 配信データ。ここの `newsquiz.json` を書き換えるだけで、
**アプリを更新せずに** 全プレイヤーの今週の問題が入れ替わります（審査も不要）。

配信URL（既存アプリが参照する固定URL）:

```
https://fdjedkdls-spec.github.io/scoregirls-news/newsquiz.json
```

## 配信構成と404の原因

配信専用リポジトリ `fdjedkdls-spec/scoregirls-news` が存在せず、Pagesが未設定だったためです。

`.github/workflows/pages.yml` はmainへのpushで問題形式・出典・今週分の存在を検査し、
成功時だけ `newsquiz.json` と `sources.json` をPagesへ公開します。
ゲーム本体のリポジトリを公開する必要はありません。

## 毎週の更新

問題は自動生成されません。毎週、出典を確認した10問以上を `weeks` に **追記** し、
`version` を +1、`updatedAt` を実際の更新日に変更します。
`sources.json` に各問題番号と一次資料URL・資料日付・確認日を記録してください。
日付を変えて過去の問題を新着扱いにすることは避けます。

配信専用リポジトリのクローンで検査してからpushします。
このフォルダをゲーム本体のチェックアウト内で使う場合は、入れ子の `git init` をせず、
配信専用クローンへ対象ファイルだけを同期してください。

```bash
python validate_feed.py --require-current
python -m unittest -v test_feed
git add newsquiz.json sources.json
git commit -m "Update weekly news questions"
git push
```

アプリは起動時にこれを取得し、端末にキャッシュします。取得できなくても
アプリ内蔵のデータで動くので、落としても事故にはなりません。

Actionsの `Validate and publish news feed` が成功した後、**固定URLそのもの**のHTTP 200、
配信されたversion・updatedAt・当週ID・内容の一致を確認してください。
GitHubへのpush成功だけを配信成功とは扱いません。CDNへの反映には時間がかかる場合があります。
次にアプリを起動し、「出題元」が今週のIDになっていることとリザルトまでの進行を確認します。
過去の問題は保持します。2026-10-24更新はversion 3、2026-W43の宇宙ニュース10問です。

### 配信が古い・停止している場合

今週の配信がないときは、保存済みの週を暦週ごとに順番に選び「今週の復習クイズ」として出題します。
画面には参加対象の暦週と元の問題の週を別々に表示し、古い問題を今週のニュースとは表示しません。
参加権は月曜開始のISO暦週で更新され、配信の復旧・同じ週の差し替えで追加の参加権は発生しません。
連続参加も配信データの並び順ではなく暦週で判定します。
新しい週の問題は引き続き編集・公開が必要です。更新が止まったときは復習表示へ戻ります。

## データの書き方

```json
{
  "version": 3,                     // 更新するたびに +1（端末側は大きいほうを採用する）
  "updatedAt": "2026-08-17",
  "weeks": [
    {
      "id": "2026-W34",             // ★一意。問題の出典週。参加権は別途ISO暦週で管理
      "start": "2026-08-17",        // ★yyyy-MM-dd。この日から「今週」として出題される
      "title": "今週の時事クイズ",
      "questions": [
        { "text": "問題文", "choices": ["正解", "誤り", "誤り", "誤り"], "answer": 0, "cat": "科学" }
      ]
    }
  ]
}
```

- `choices` は **必ず4つ**、`answer` は正解の添字（0〜3）。アプリ側で毎回シャッフルして
  表示するので、**書くときは正解を先頭（`"answer": 0`）に固定**しておくと楽です。
- 1週あたり **10問以上**推奨（週替わりチャレンジが10問、トーナメントは過去分も含めて15問出す）。
- `cat` は表示用のカテゴリ。科学 / テクノロジー / 国際 / 経済 / 環境 / スポーツ / 教養 / 社会 など。
- 過去の週は消さないでください。**トーナメントの問題プール**として使われます。
- 壊れた週（id が無い・選択肢が4つでない・答えが範囲外）は端末側で自動的に読み飛ばします。

## ★出題ルール（審査事故を防ぐため必ず守る）

問題をアプリとは別に更新できるため、新規配信は子どもにも適した科学・技術・一般教養を中心にします。
ストアの審査状況はこのREADMEからは判断せず、以下の編集方針を守ってください。

- **実在の存命人物を名指ししない**（とくに否定的・評価的な文脈で）
- **政治・選挙・戦争・紛争・事件事故・宗教**を扱わない
- 「今の世の中を知る」枠として、**科学・技術・環境・経済のしくみ・スポーツ・一般教養**に寄せる
- 断定できない、あるいは正解が将来変わりうる事柄は避ける（例：現在進行中の出来事）
